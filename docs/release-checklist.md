## ۱. تایید زنجیره کامل ارزش (End-to-End Chain Verification)

زنجیره پیوسته زیر به طور کامل تست، اعتبارسنجی و تایید شده است:

```text
[۱. دانلود مدل]
      │  (دانلود با پیشرفت بایتی و ذخیره در Cache Storage)
      ▼
[۲. استنتاج سرد آفلاین]
      │  (WebLLM در Web Worker با شتاب‌دهنده WebGPU بدون اینترنت)
      ▼
[۳. ورود داده‌های تاریخی]
      │  (داده‌های CSV بدون بایاس منطقه زمانی و بدون نشت آینده)
      ▼
[۴. استخراج فیچرهای S0]
      │  (شناسایی پیوت‌ها، سوییپ‌ها، BOS و نواحی FVG)
      ▼
[۵. شبیه‌ساز رویدادمحور]
      │  (تزریق ساعت مجازی و اجرای سفارش در دفتر کل طلایی)
      ▼
[۶. ارزیابی متوالی AI]
      │  (تحلیل‌گر و منتقد متوالی با اعتبارسنجی اسکیما و شواهد)
      ▼
[۷. فید داده زنده آنلاین]
      │  (دریافت قیمت لحظه‌ای XAUUSD و EURUSD و محاسبه اسپرد)
      ▼
[۸. پیپرتریدینگ زنده (Paper Live)]
      │  (پر شدن با قیمت زنده، صفر فراخوانی به بروکر، نشانگر رسمی)
      ▼
[۹. پیش‌نویس سفارش و کلید یکتا]
      │  (Idempotency Key ضد تکرار و اعتبارسنجی Epoch تک‌مجری)
      ▼
[۱۰. تایید دستی دمو توسط حامد]
      │  (تایید صریح کاربر با عمر ۴۵ ثانیه و ارسال به cTrader Demo)
      ▼
[۱۱. تطبیق و بازتطبیق محافظتی]
         (تایید حد ضرر در بروکر، رفع وضعیت‌های مبهم با Reconciliation)
```

  - [x] تخلیه حافظه گرافیکی با `unload()` و امکان حذف از کش

  - [x] انتخابگر منطقه زمانی (UTC، سیدنی، ایران، لندن، نیویورک)
  - [x] استراتژی استاندارد S0 و استخراج فیچرهای ساختاری

- [x] **بسته W3 (مقایسه مدل و بنچمارک ۱۲۰ موردی):**

## ۳. دستورالعمل نصب و اجرای لوکال (Installation & Runbook)

```bash
# ۱. کلون مخزن گیت‌هاب
git clone https://github.com/hamedharami-hub/Tradewithhamed.git
cd Tradewithhamed

# ۲. نصب وابستگی‌ها
npm install

# ۳. تنظیم فایل متغیرهای محیطی
cp .env.example .env.local

# ۴. اجرای سرور توسعه محلی
npm run dev

# ۵. بیلد تولیدی و تایید نوع داده‌ها
npx tsc --noEmit
npm run build
```

## ۴. تاییدیه نهایی انتقال (Handoff Confirmation)
تمامی تغییرات در مخزن رسمی گیت‌هاب حامد حرمی‌پور روی شاخه `main` همگام‌سازی و پوش گردیده‌اند. هیچ فایل مخفی یا خارج از مخزنی وجود ندارد و نسخه آنلاین گوگل استودیو مستقیماً از روی این کامیت‌ها قابل اجراست.
