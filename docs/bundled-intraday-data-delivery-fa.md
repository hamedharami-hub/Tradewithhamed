# تحویل دادهٔ intraday داخل اپ

**وضعیت:** آماده برای مرحلهٔ بعدی Backtest پژوهشی

دادهٔ عمومی HistData برای `EURUSD`، `GBPUSD` و `USDJPY` آماده‌سازی و داخل اپلیکیشن قرار گرفت. برای هر نماد، دادهٔ M1 از منبع محلی به 5M تجمیع deterministic شد و فقط کندل‌های 5 دقیقه‌ای بسته‌شده در public bundle قرار گرفتند. رابط Research Desk اکنون برای نماد انتخابی دکمهٔ «بارگذاری دادهٔ ۵ دقیقه‌ای سال ۲۰۲۴» دارد؛ پس از بارگذاری، داده داخل مرورگر parse و quality-check می‌شود و Backtest محلی قابل اجرا است.

| نماد | منبع پایه | دیتاست داخل اپ | تعداد 5M | بازه | وضعیت پایه |
|---|---|---|---:|---|---|
| EURUSD | HistData M1 2024 | `histdata-eurusd-5m-2024.csv` | 74,887 | 2024-01-01 تا 2024-12-31 | READY؛ 316 گپ ثبت‌شده |
| GBPUSD | HistData M1 2024 | `histdata-gbpusd-5m-2024.csv` | 74,875 | 2024-01-01 تا 2024-12-31 | PARTIAL؛ 60 ردیف تکراری حذف شد، 386 گپ ثبت‌شده |

## محدودیت و تفسیر

این داده‌ها **public research data** هستند، نه دادهٔ broker-match. بنابراین برای طراحی، Backtest، Walk-Forward و مقایسهٔ روش‌ها قابل استفاده‌اند؛ اما اختلاف احتمالی در spread، timezone، rollover، قیمت‌دهی و قرارداد نماد با broker مشخص را ثابت نمی‌کنند. هیچ نتیجهٔ این مرحله به‌عنوان نتیجهٔ Live Trading یا تضمین سود تفسیر نمی‌شود.

دادهٔ M1 کامل در مسیر `data/datasets/histdata/` باقی مانده است و برای اجرای محلی یا import دستی قابل استفاده است، اما عمداً به public bundle مرورگر افزوده نشد تا بارگذاری اولیه و مصرف حافظهٔ اپ سنگین نشود. نسخهٔ داخل اپ 5M است و برای شروع سریع و پایدار مرحلهٔ بعد انتخاب شده است.

## Validation انجام‌شده

`npm run typecheck`، `npm run lint`، `npm run test:domain` و `npm run build` موفق شدند. نتیجهٔ domain smoke برابر با 23 suite، 130 check و صفر failure بود. فایل‌های CSV، manifest و checksum در `public/historical/intraday/manifest.json` ثبت شده‌اند. هیچ broker API، سفارش یا مسیر نوشتاری در این تغییر فعال نشده است.

## مرحلهٔ بعد

مرحلهٔ بعد اجرای یک ماتریس کنترل‌شدهٔ Backtest روی همین سه نماد و 5M است: ابتدا baseline بدون AI، سپس شورای قطعی آفلاین؛ بعد از آن Walk-Forward ثابت و cost stress. پارامترهای استراتژی در این مرحله دست‌کاری نمی‌شوند و اجرای سنگین فقط پس از تأیید خروجی baseline انجام خواهد شد.
