# تحویل دادهٔ intraday داخل اپ

**وضعیت:** آماده برای مرحلهٔ بعدی Backtest پژوهشی

دادهٔ عمومی HistData برای `EURUSD`، `GBPUSD` و `USDJPY` آماده‌سازی و داخل اپلیکیشن قرار گرفت. برای هر نماد، دادهٔ M1 سال ۲۰۲۴ داخل bundle قرار دارد و تایم‌فریم‌های `5M`، `15M`، `1H`، `4H`، `D1` و `W1` به‌صورت deterministic از همان M1 ساخته شده‌اند. رابط Research Desk اکنون با انتخاب تایم‌فریم، فایل آمادهٔ همان بازه را بارگذاری و داخل مرورگر parse و quality-check می‌کند.

## محدودیت و تفسیر

این داده‌ها **public research data** هستند، نه دادهٔ broker-match. بنابراین برای طراحی، Backtest، Walk-Forward و مقایسهٔ روش‌ها قابل استفاده‌اند؛ اما اختلاف احتمالی در spread، timezone، rollover، قیمت‌دهی و قرارداد نماد با broker مشخص را ثابت نمی‌کنند. هیچ نتیجهٔ این مرحله به‌عنوان نتیجهٔ Live Trading یا تضمین سود تفسیر نمی‌شود.

دادهٔ M1 داخل bundle قرار گرفته است، اما فقط با کلیک کاربر بارگذاری می‌شود تا بارگذاری اولیهٔ اپ سنگین نشود. در اجرای Backtest تعاملی، بازهٔ تاریخی را محدود کنید؛ برای M1 کامل سالانه ممکن است سقف تعاملی مرورگر فعال شود. دادهٔ خام و artifactهای چندساله در مسیر `data/datasets/histdata/` نیز باقی مانده‌اند.

## Validation انجام‌شده

`npm run typecheck`، `npm run lint`، `npm run test:domain` و `npm run build` موفق شدند. نتیجهٔ domain smoke برابر با 23 suite، 130 check و صفر failure بود. فایل‌های CSV، manifest و checksum در `public/historical/intraday/manifest.json` ثبت شده‌اند. هیچ broker API، سفارش یا مسیر نوشتاری در این تغییر فعال نشده است.

## مرحلهٔ بعد

مرحلهٔ بعد اجرای یک ماتریس کنترل‌شدهٔ Backtest روی همین سه نماد و تایم‌فریم‌های منتخب است: ابتدا baseline بدون AI، سپس شورای قطعی آفلاین؛ بعد از آن Walk-Forward ثابت و cost stress. پارامترهای استراتژی در این مرحله دست‌کاری نمی‌شوند و اجرای سنگین فقط پس از تأیید خروجی baseline انجام خواهد شد.
