## Backtest

سناریوی زیر end-to-end اجرا شد:

1. انتخاب نماد `EURUSD`؛
2. بارگذاری دادهٔ ۵ دقیقه‌ای سال ۲۰۲۴ از HistData؛
3. تنظیم بازهٔ `2024-01-02` تا `2024-01-05`؛
4. اجرای Backtest؛
5. مشاهدهٔ خروجی و معیارها.

خروجی قابل مشاهده در رابط:

| معیار | مقدار |
|---|---:|
| کندل‌های پردازش‌شده | ۱٬۱۲۸ |
| تعداد معاملات | ۲۶۱ |
| بازده خالص | ۳۰٫۹۲٪- |
| بیشینه افت سرمایه | ۳۱٫۶۳٪ |
| Profit Factor | ۰٫۴۵ |

منبع داده در رابط به‌درستی `EURUSD پنج‌دقیقه‌ای، سال ۲۰۲۴ · HistData aggregated · EURUSD` نمایش داده شد. این اعداد فقط نتیجهٔ همین dataset، بازه و تنظیمات هستند و ادعای عملکرد آینده نیستند.

## Replay

بعد از Backtest، حالت «بازپخش بازار» انتخاب شد. کنترل‌ها به این شکل آزمون شدند:

| کنترل | نتیجه |
|---|---|
| ورود به حالت Replay | موفق |
| مقدار اولیه | `20 / 1,128 کندل` |
| گام دستی کندل بعدی | موفق؛ `20` به `21` رسید |
| پخش خودکار | موفق؛ `21` به `23` طی حدود ۱٫۵ ثانیه رسید |
| توقف پخش | موفق؛ مقدار روی `23` ثابت ماند |
| شروع مجدد | موفق؛ مقدار به `20 / 1,128 کندل` برگشت |
| نمایش تحلیل رژیم و ستاپ | موفق |

Replay فقط کندل‌های تا شاخص جاری را به نمودار و ارزیابی استراتژی ارائه کرد. هیچ اتصال یا مسیر نوشتاری broker در این آزمون استفاده نشد.

## نتیجه

جریان‌های انتخاب نماد، بارگذاری داده، تنظیم تاریخ، اجرای Backtest، ورود به Replay، گام‌برداری، پخش، توقف و reset همگی پاسخ‌گو بودند. در خود رابط runtime error یا خطای ناشناخته مشاهده نشد.

ابزار مشاهدهٔ console مرورگر به‌دلیل خطای encoding در پیام‌های داخلی، لاگ قابل‌خواندن برنگرداند؛ این محدودیت ابزار مشاهده بود و مانع اجرای سناریوهای تعاملی نشد.
