# Stage 18: Replay تاریخی معادل ۳۰ روز

## دامنه

به‌دلیل نبود credential و endpoint cTrader Demo، اجرای live read-only شروع نشد. برای آماده‌سازی مسیر، آخرین ۳۰ روز تقویمی موجود در dataset تاریخی GBPUSD/4H با ۱۴۰ کندل warmup بازپخش شد. این خروجی **Paper-Forward زنده نیست** و فقط شبیه‌سازی تاریخی است.

## نتیجه

| شاخص | مقدار |
|---|---:|
| بازهٔ ارزیابی | ۲۰۲۴-۱۲-۰۱ تا ۲۰۲۴-۱۲-۳۱ UTC |
| کندل warmup | ۱۴۰ |
| کندل ارزیابی | ۱۳۳ |
| ردیف روزانه | ۲۷ |
| سیگنال | ۲ |
| سفارش فرضی | ۲ |
| معاملات بسته‌شده | ۱ |
| معاملات برنده | ۰ |
| معاملات بازنده | ۱ |
| Net PnL | -۲۱٫۸۴ |
| Profit Factor | ۰ |
| Max Drawdown | ۰٫۴۴٪ |
| وضعیت | `COMPLETE` |

یک معامله در پایان بازه همچنان باز بود؛ بنابراین این replay کوتاه برای پذیرش یا رد candidate کافی نیست و فقط صحت مسیر روزانه و گزارش‌گیری را نشان می‌دهد.

## کنترل‌ها

`brokerWrites=false`، `liveFeed=false` و `liveTrading=false` در artifact ثبت شده‌اند. هیچ broker، exchange یا order-writing API فراخوانی نشد. داده‌ها عمومی HistData و broker-match نیستند.

## مرحلهٔ باقی‌مانده

برای اجرای واقعی ۳۰روزه فقط یک Gate خارجی باقی مانده است: فراهم‌شدن credential و endpoint Demo read-only و عبور موفق preflight. پس از آن، monitor موجود می‌تواند روی feed کندل بستهٔ cTrader اجرا شود. تا آن زمان، replay تاریخی و آماده‌سازی کد تکمیل‌شده تلقی می‌شود.
